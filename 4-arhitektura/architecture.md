# Жүйе архитектурасы

## 1. Жүйенің жалпы құрылымы
Жүйе колледж жабдықтарын есепке алу және жөндеу өтінімдерін басқаруға арналған.

## 2. Негізгі модульдер
- Жабдықтарды есепке алу
- Жөндеу өтінімдерін басқару
- Пайдаланушыларды басқару
- Іздеу және сүзу

## 3. Пайдаланушылар
- Әкімші
- Қызметкер

## 4. Деректер базасы
Жүйеде жабдықтар, пайдаланушылар және жөндеу өтінімдері туралы ақпарат сақталады.

## 5. Интерфейс
Интерфейс қарапайым, түсінікті және пайдалануға ыңғайлы болуы керек.
## 6. Архитектура түрлерін салыстыру

### Монолит
Барлық функциялар бір қосымша ішінде орналасады.
Артықшылығы: жасау және іске қосу оңай.
Кемшілігі: жүйе үлкейгенде өзгерту қиын.

### MVC
Жүйе Model, View және Controller бөліктеріне бөлінеді.
Артықшылығы: құрылымы түсінікті, кодты басқару жеңіл.
Кемшілігі: бастапқыда құрылымын жасау күрделірек.

### Клиент-сервер
Клиент серверге сұраныс жібереді, сервер деректерді өңдейді.
Артықшылығы: деректерді орталықтан басқару.
Кемшілігі: серверге тәуелді.

## 7. Таңдалған архитектура

MVC архитектурасы таңдалды.
Ол жүйені интерфейс, деректер және логика бөліктеріне бөледі.
Бұл құрылым жабдықтарды және жөндеу өтінімдерін басқаруды жеңілдетеді.

## 8. Технологиялар

- Python — бағдарламалау тілі
- Flask — веб-фреймворк
- SQLite — деректер базасы
- HTML — веб-беттер
- CSS — дизайн
- Figma — интерфейс макеттері
- draw.io — диаграммалар
